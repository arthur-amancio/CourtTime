# Capturas

- `v1/` — primeira versão, avaliada na revisão externa de 20/10/2026.
- `v2/` — versão refinada a partir dessa revisão. Destaques:
  - `login--390.png`, `login--430.png`: login no celular;
  - `calendario-opcao-a-390.png`, `calendario-opcao-b-390.png`: variantes do calendário;
  - `upload-vazio-componente.png`, `upload-selecionado-componente.png`, `upload-erro-componente.png`: envio de PDF;
  - `menu-movel-aberto-390.png`: menu móvel;
  - `nova-solicitacao-zoom200-foco.png`, `nova-solicitacao-zoom400-foco.png`, `teclado-virtual-390x420.png`: zoom e teclado virtual;
  - `detalhe-*.png`: as oito situações do detalhe da solicitação;
  - `testes-teclado-zoom.json`: resultado bruto das 52 verificações.
