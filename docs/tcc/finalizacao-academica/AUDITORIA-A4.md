## Comandos e limites

- Exportação nativa do Google Docs para PDF; cálculo de páginas por paginar.py; nova exportação e comparação dos 103 títulos.
- auditar_pdf.py sobre o arquivo final: A4, margens, páginas vazias, foliação e pranchas de todas as82 folhas.
- extrair-figuras.py:33 imagens e catálogo de integridade.
- modelagem-profissional/validar.ps1: nove conjuntos editáveis, dimensões PNG e presença das exportações; aprovado após a correção de varchar(64).
- Sintaxe dos três scripts Python e do gerador Node conferida. Nenhum teste Java ou jornada Playwright foi repetido nesta fase.

O PDF é candidato para revisão do orientador; não equivale à aprovação acadêmica final. As pendências P1/P2 estão na checklist de entrega. A paginação do Docs é texto estático e o rodapé é materializado no PDF: qualquer edição posterior invalida esta prova até nova exportação.
